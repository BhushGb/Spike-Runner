# Spike Runner

A fast-paced browser survival game. Jump over red spikes, collect green fuel, and invert gravity with yellow feeds. How long can you survive?



## How to Play

1. Open `Spike Runner.html` https://htmlpreview.github.io/?https://github.com/BhushGb/Spike-Runner/blob/main/Spike-Runner.html in any modern browser.
2. Press **Enter** or click to open the theme selector.
3. Choose **black** or **white** theme.
4. Jump and survive as long as you can.

**Objective**  
Survive as long as possible.  
- Jump red spikes  
- Grab green fuel  
- Touch yellow to invert gravity  
- Score rises the longer you play



## Strength System

| Action                              | Effect              |
|-------------------------------------|---------------------|
| Initial strength                    | 3                   |
| Red spike hit                       | −1 strength         |
| Green strength fuel                 | +1 strength         |
| 1 more red collision at 0 strength  | **GAME OVER!**      |



## Controls

| Input                | Action              |
|----------------------|---------------------|
| Space / Click / Tap  | Jump                |
| B (hold)             | Slow the game       |
| N (hold)             | Speed up            |
| P                    | Pause / Resume      |
| ← / → Arrows         | Select theme        |
| Enter                | Confirm / Continue  |
| T (on Game Over)     | Change theme        |



## Key Objects

- **Red Spikes** – Point up (from bottom) or down (when inverted). Each hit costs 1 strength.
- **Green Strength Fuel** – Restores +1 strength.
- **Yellow Gravity Feed** – Inverts gravity and gives a short safe period.



## Tips

- Jump early for tall spikes  
- Hold **B** when the screen gets crowded  
- Grab green fuel when your strength is low  
- Use the safe window after a gravity flip  

**Jump → Avoid → Collect → Shift → Survive**
